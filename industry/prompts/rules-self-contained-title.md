
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 研究团队 / 期刊名 / 药物或技术名称。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代号 / 数字 / 没信息量的 teaser（如 "Day 1"、"Big news"、"A new paper"）时，结合【来源】和正文把主体补进标题。例：原标题 "New results in base editing" + 来源 "Broad Institute" → "Broad Institute 公布碱基编辑的新结果"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体机构或团队时，用上位词（如"某研究团队"）兜底，绝不凭"学科常识"编一个具体机构名 / 期刊名 / 基因名 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Outlook 这类解释、分析、方法讲解或综述标题，中文标题必须保留这个类型；不能因为正文谈到一篇已经发表的论文、一个已有的数据集或一项新结果，就改写成“发表 / 公布 / 获批 / 上线”。只有原标题明确宣布了发表、公布、获批或上线，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、期刊、药物或技术名。
   例：原标题 "How CRISPR screens reshape drug target discovery" → "CRISPR 筛选如何改变药物靶点发现"，不能写成 "某团队发表新的 CRISPR 筛选方法"。
   例：原标题 "How to read a forest plot" + 来源和正文明确是 Cochrane → "Cochrane 如何解读森林图"，不能只写成缺主体的 "如何解读森林图"。
